# 종목별 데이터 저장

프로젝트 루트 stocks/KR/KOSPI 또는 stocks/KR/KOSDAQ 아래 종목명_종목코드.json 파일에 저장합니다. 미국 NASDAQ 폴더는 향후 확장용이며 현재 수집 대상이 아닙니다.

앱은 stocks/index.json에서 종목코드별 경로와 최신 종목 정보를 읽고, 해당 종목 JSON의 bars를 차트에 사용합니다. 데이터가 없으면 기본 등록 목록과 빈 데이터 상태를 표시합니다.

수집기는 날짜별 KRX 응답을 각 종목 파일에 즉시 합칩니다. 동일 날짜는 교체하며 일봉은 날짜순입니다. 파일에는 OHLCV, 거래대금, 시총, 상장주식수, 등락률과 출처/원본가격 여부/수집 구간을 저장합니다. 종목명이 변경되면 새 이름으로 저장 후 이전 파일을 제거하고 index 경로를 갱신합니다. 파일명 금지 문자는 밑줄로 치환합니다. 파일은 임시 파일을 거쳐 교체합니다. 날짜/시장 완료 내역은 collection-status.json에 기록하며 부분 저장 실패 시 재조회로 복구합니다.

수동 실행(사용자가 수집 재개를 승인한 뒤): node scripts/backfill-krx.mjs 20100104 20261008 100
단일 거래일: node scripts/collect-krx.mjs 20261008

현재 수집은 중지 상태입니다. 자동 실행 예약은 없습니다. 이번 변경에서는 실제 API 호출이나 종목 데이터 생성 없이 임시 폴더로 저장 동작만 테스트했습니다.

락 파일 collection.lock으로 동시 수집을 차단합니다. 강제 종료로 락이 남으면 실제 수집 프로세스가 없는지 확인 후 락을 제거해야 합니다. 비어 있는 날짜 응답은 미공개/휴장 구분이 불확실하므로 완료 처리하지 않습니다. 원본 가격은 수정주가가 아닙니다. 과거 수집이 일부 완료됐다는 이유만으로 전체 기간 완료로 표시하지 않습니다.

로컬 영구 디스크를 전제로 하며 서버리스 배포에서는 영구 저장소로 변경해야 합니다. 삭제한 이전 data/local 데이터는 복원하지 않습니다.
